# GeraArteIA

Sistema acadêmico de geração de imagens por Inteligência Artificial.

O projeto utiliza Stable Diffusion 1.5 para geração de imagens a partir de descrições em português.

## Tecnologias

- Python
- PyTorch
- Diffusers
- Stable Diffusion 1.5
- Gradio
- Hugging Face Spaces

## Funcionamento

O usuário informa uma descrição em português.

O sistema:

1. Recebe o prompt.
2. Identifica a categoria da solicitação.
3. Otimiza automaticamente o prompt.
4. Envia o prompt para o Stable Diffusion.
5. Gera a imagem.
6. Exibe o resultado no navegador.

Projeto desenvolvido para fins acadêmicos.
